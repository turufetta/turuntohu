# Turufetta's Ureshino Onsen Yudofu Game

つるふぇった（Turufetta）の嬉野温泉湯豆腐をテーマにしたブラウザミニゲームです。

## 遊び方

1. 箸で食材をキャッチ  
2. 鍋に盛り付け  
3. ちょうどよく煮る  
4. ごまだれで食べる  

### 難易度

| 段位 | 目標 | 開放条件 |
|------|------|----------|
| 初級 | 20品 | 最初から |
| 中級 | 30品 | 初級クリア |
| 上級 | 40品 | 中級クリア |

## 言語

日本語 / English / 한국어 / Українська / 中文（設定から変更）

## 起動方法

```bash
# そのまま index.html を開くか
python3 -m http.server 8080
```

### GitHub Pages

1. リポジトリに push  
2. Settings → Pages → Source: `main` / root  
3. `https://<user>.github.io/<repo>/` で公開
